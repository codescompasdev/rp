# MoveLink — Next-gen logistički softver za Evropu

MoveLink je sve-u-jednom SaaS platforma za transport, skladište i flotu. Fokus na SMB prijevoznike u Njemačkoj i Evropi — bez kompleksnih implementacija, s AI optimizacijom i modularnim pristupom.

---

## Vizija

Inteligentna platforma za upravljanje logističkim operacijama „od pick-up do delivery“ — TMS + WMS + Fleet + AI u jednom sistemu. Plug-and-play za male i srednje firme, skalabilno za enterprise.

---

## Moduli

### Core Logistics Suite

| Modul | Opis |
|-------|------|
| **TMS** | Transport Management System — planiranje ruta, dispatch, real-time tracking, ETA |
| **WMS** | Warehouse Management System — skladište, zone, RFID/Barcode, kretanje robe |
| **Fleet** | Upravljanje flotom — vozila, vozači, održavanje, gorivo, registracije |
| **Gate** | Kapija i vaganje — kontrola ulaza/izlaza, najave, truck-on-site |
| **Kontejneri** | Praćenje kontejnera — lokacija, status, dani kod klijenta |

### AI moduli (disruptivno)

| Modul | Opis |
|-------|------|
| **AI Route Optimizer+** | Multi-stop optimizacija, LTL/FTL clustering, učenje iz historije |
| **AI Cargo Packing** | 3D pakovanje tereta, maksimalna popunjenost vozila |
| **Predictive ETA** | Predviđanje kašnjenja na osnovu saobraćaja i historije |
| **Dynamic Pricing** | Automatsko izračunavanje cijene transporta, real-time ponude |

### Operativni moduli

| Modul | Opis |
|-------|------|
| **Driver App** | Mobilna aplikacija za vozače (iOS/Android) — nalozima, status, navigacija |
| **Dispatcher Dashboard** | Real-time mapa, ETA, upravljanje rutama |
| **Customer Portal** | Praćenje pošiljke, chat, SLA upozorenja |
| **Shipment Analytics** | Analitika, trendovi, heatmap, izvještaji |

### Integracije & IoT

| Tip | Primjeri |
|-----|----------|
| GPS telematika | Samsara, Geotab, TomTom |
| ERP/CRM | SAP, Odoo, DATEV |
| Barcode/RFID | Zebra, Honeywell |
| IoT senzori | Temperatura, vlažnost (hladnjača) |

### Compliance & Sustainability

| Modul | Opis |
|-------|------|
| **Green Routing** | CO2 tracking, optimizacija za manju emisiju |
| **EU Compliance** | Carina, EUR.1, regulative |

## Zašto MoveLink?

- **Sve u jednom** — TMS + WMS + Fleet + AI u jednom SaaS-u
- **Plug-and-play** — bez dugih implementacija
- **SMB fokus** — cijena 199–499 €/mj umjesto enterprise cijena
- **AI moduli** — route, packing, ETA, pricing u jednom sistemu
- **Mobilna app** — za vozače i dispečere
- **Modularnost** — plaćaš samo šta koristiš

## Tržište

- **~4M logističkih firmi** u Evropi
- **Njemačka** — glavno logističko čvorište EU
- **Ciljni ICP** — firme sa 10–150 vozila
- **Go-to-market** — Njemačka → DACH → Zapadna Evropa → Pan-EU
